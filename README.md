# EstateAI India – House Price Prediction

An AI/ML-based project that predicts residential property prices in India using machine learning.

## Features
- Indian housing dataset analysis
- Data cleaning and preprocessing
- Random Forest and Extra Trees models
- House price prediction in Indian Rupees
- Interactive Streamlit web application
- Prediction history
- Download prediction reports as PDF
- Export prediction history as CSV

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- ReportLab

## Model Performance
- Algorithm: Extra Trees Regressor
- Mean Absolute Error (MAE): 25.09 Lakhs
- R² Score: 60.56%

## How to Run

1. Install dependencies:

   `pip install -r requirements.txt`

2. Train the model:

   `python src/train_extra_trees.py`

3. Start the application:

   `streamlit run app.py`

## Dataset
The dataset is not included in this repository. Place your dataset files in the `data/` folder before running the training scripts.
